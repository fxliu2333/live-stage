直播演播厅 · 安装前后须知

一、系统要求
   Windows 10 / 11（64 位）。
   界面用 Microsoft Edge WebView2 显示。安装包已内置微软官方的 WebView2 引导程序，
   检测到缺失会自动静默安装（需要联网）。

二、虚拟声卡（必须，装完要重启一次电脑）
   AI 声音要伪装成麦克风交给直播伴侣，需要 VB-Audio Virtual Cable。
   VB-Cable 的授权条款明确不允许把它打包进其他安装程序，所以安装包不能内置它。
   安装最后会弹一个提示，点「是」会打开官方下载页：
        https://vb-audio.com/Cable/
   下载后解压，右键 VBCABLE_Setup_x64.exe →「以管理员身份运行」→ 装完重启电脑。

   重启后打开程序，顶栏显示「已检测到 VB-Cable」才算就绪；
   如果仍显示缺少，检查是否装完没重启。

三、装好之后怎么用
   1. 桌面会出现「直播演播厅」，双击打开，会同时出现控制台和演播窗口（标题 STAGE）。
   2. 「高级设置 → 声音链路」：程序声音输出到选 CABLE Input (VB-Audio Virtual Cable)。
      注意这里列的是播放设备，不是麦克风。
   3. 抖音直播伴侣 → 添加素材 → 窗口捕获 → 选标题为 STAGE 的窗口。
   4. 直播伴侣 → 麦克风 → 选 CABLE Output (VB-Audio Virtual Cable)。
   5. 控制台里填直播间地址、导入口播稿，点「一键开播」。

四、数据放在哪
   配置、语音缓存、抖音登录态都在：%LOCALAPPDATA%\LiveStage
   卸载程序不会删除这个目录，重装后登录态和语音还能继续用。

五、卸载
   设置 → 应用 → 直播演播厅 → 卸载。
   虚拟声卡不会被卸载，需要的话到 VB-Cable 安装目录运行卸载程序。
